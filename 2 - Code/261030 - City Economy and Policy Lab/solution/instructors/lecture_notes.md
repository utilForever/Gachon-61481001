## 12. 만족도 계산 확인

경과 시간: 16.5–17.5분

- 음수가 되는 점수는 0으로 제한하고, 계산 결과를 그대로 반환한다.

```python
commute_score = 0 if commute_min is None else 100 * max(0, 1 - commute_min / 60)
rent_score = 0 if income == 0 else 100 * max(0, 1 - rent / income)
return 0.5 * commute_score + 0.3 * rent_score + 0.2 * environment
```

**교수자 설명**

commute_min이 None이면 도달할 수 없는 경우이므로 통근 점수를 0으로 둔다. 후보의 입주 가능 여부는 지원 코드가 별도로 검사한다. 소득이 0이면 주거비 점수는 0이다. 최종 합산값을 반올림하지 않고 반환한다.

**다음 내용으로 연결:** 점수가 낮더라도 바로 이사하지 않도록 지속 기간과 자원을 확인한다.

## 39. 이웃 비율 계산 확인

경과 시간: 71.5–72.5분

- 분모는 빈칸을 제외한 이웃 수이고, 현재 행위자는 포함하지 않는다.

```python
neighbor = grid[ny][nx]
if neighbor is not None:
    occupied += 1
    if neighbor == grid[y][x]:
        same += 1

return same / occupied if occupied else None
```

**교수자 설명**

앞 장의 조건으로 유효한 이웃 좌표만 남겼다. 각 이웃에서 빈칸을 제외하고 occupied를 늘린다. 현재 위치와 유형이 같으면 same도 늘린다. same과 occupied는 반복문 전에 0으로 초기화한다. 이웃이 없을 때 반환한 None은 제공 코드에서 만족으로 처리한다.

**다음 내용으로 연결:** 이 비율을 새 위치에서 계산할 때는 이동할 행위자의 출발지를 먼저 고려해야 한다.
