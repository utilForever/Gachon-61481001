# 제공 자료

## 관측 자료: observations.csv

이 파일은 최신 관측값을 반영하는 규칙을 확인하기 위해 만든 **예제 관측 자료**입니다. 실제 센서나 병원에서 수집한 자료가 아닙니다.

- `target_id`: 대상 식별자. `H`는 병원, `W`는 급수 시설입니다.
- `unit`: 값의 단위. 병원 대기 인원의 단위는 `명`입니다.
- `value`: 관측값. 빈 칸은 누락, `0`은 실제 값이 0이라는 뜻입니다.
- `observed_at`: 관측한 시각. 당일 0시부터 지난 분으로 기록합니다. `605`는 10시 5분입니다.
- `received_at`: 자료를 받은 시각. 최신값 여부는 이 항목이 아니라 `observed_at`으로 판단합니다.
- `case`: 해당 행에서 확인할 상황입니다.

CSV의 순서대로 한 행씩 수신합니다. 초기 관측값은 병원 H의 10시 대기 인원 8명입니다. 처리 결과는 반영 → 반영 → 과거 관측 → 같은 관측 시각 → 대상 불일치 → 단위 불일치 → 값 누락 → 반영 순입니다. 마지막 값 0명도 정상적으로 반영합니다.

예제 관측값은 별도 상태에 저장합니다. 도시 모형이 계산한 병원 대기 인원이나 서비스 시각을 덮어쓰지 않습니다. 관측 자료의 시각(시:분)과 모형의 경과 시간(시간째)은 서로 다른 기준입니다. 두 값을 나란히 보여줄 수 있지만 같은 순간의 실측·예측 오차로 해석하지 않습니다.

## 지도 자료: map_example.json

이 파일은 **OpenStreetMap의 node·way·tag 구조를 본뜬 가상 자료**입니다. 실제 OSM에서 내려받은 자료가 아니며 실제 도시의 위치나 형상을 나타내지 않습니다. OSM의 일반적인 위경도 좌표 대신 수업에 필요한 미터 좌표 `x`, `y`를 미리 제공했습니다. 좌표 투영은 이번 실습의 작성 대상이 아닙니다.

- 점: 시설 위치를 `node`와 `amenity` 태그로 표현합니다.
- 선: 도로를 노드의 연결 순서와 `highway` 태그로 표현합니다.
- 면: 건물을 처음과 마지막 노드가 같은 닫힌 `way`와 `building` 태그로 표현합니다.
- 태그: 이름이나 시설 종류 등의 속성을 담습니다. 없는 속성을 추측해서 채우지 않습니다.

지원 코드가 노드 참조를 풀어 점·선·면 좌표로 바꿉니다. 도로는 선분을 일정 간격으로 표본화한 뒤 격자에 배치합니다. 건물은 대표점 하나를 한 셀에 배치합니다. 건물의 실제 면적이나 도로 폭을 보존하지 않는 단순화입니다. 여러 시설이 한 셀에 들어갈 수 있고 세부 형상도 사라지므로 원자료와 격자 결과를 함께 확인해야 합니다.

지도는 가로 100m, 세로 80m, 20m 셀의 4행×5열입니다. 원점은 왼쪽 아래 (0, 0)이며 화면의 0행은 위쪽입니다. 하한은 포함하고 상한은 제외합니다. 따라서 (0, 0)은 (3, 0) 셀, (100, 20)은 지도 밖입니다. 범위 밖 시설도 자료에 포함해 제외 결과를 확인하도록 했습니다.

가져오기 결과는 미리 보기로만 표시하며 기존 도시 상태를 자동으로 바꾸지 않습니다. 모형 안의 주거지 A~D와 이 파일의 건물은 서로 다른 자료입니다. 이 실습은 데이터 표현·검증·연결 규칙을 연습하는 단계이며 실제 도시와 지속적으로 동기화되는 디지털 트윈을 완성한 것은 아닙니다.
