## Course description

This course involves conducting projects designed to understand virtual spaces and the metaverse from the perspective of dynamic systems. Students use Python to design virtual cities (similar to the game SimCity) and simulate the process by which cities grow or decline as various elements interact. They also apply various scenarios related to urban policy and compare and analyze the results.
